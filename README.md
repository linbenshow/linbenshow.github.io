# 林聖邦 Ben｜工程作品集

開啟 `index.html` 即可預覽。網站使用原生 HTML、CSS 與 JavaScript，無須安裝套件或執行建置。

## GitHub Pages

將這個資料夾內的檔案放到 `linbenshow/linbenshow.github.io` 儲存庫的根目錄。在 **Settings → Pages** 選 **Deploy from a branch**，來源設為 **main / (root)**。

`resume.html` 是公開履歷頁，可以用頁首的「列印／存成 PDF」輸出。首頁的 3D 棧板圖是堆疊示意，實際操作可開啟專案旁的線上 Demo。
